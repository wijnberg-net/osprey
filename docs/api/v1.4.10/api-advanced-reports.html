Get Enhanced Stability Report

GET /api/v1/reports/stability?window=24h&area_id=<uuid>
GET /api/v1/reports/stability?window=7d&pi_id=<uuid>

Enhanced routing stability report with severity classification (ok/warning/high/critical) and per-area instability scoring (0-100). Identifies flapping links by state change frequency and unstable routers by adjacency reset and event counts. Supersedes the basic GET /api/v1/diagnostics/stability endpoint with richer data.

Auth: Any authenticated user.

Query parameters:

  • Scope: area_id, area_ids, pi_id, rd_id, or network_id (same as diagnostics endpoints)
  • window -- Time window: 1h, 6h, 24h (default), 7d, 30d

Response: 200 OK

Severity thresholds:

  • Flapping links: ok (<4), warning (4-7), high (8-15), critical (16+) state changes
  • Unstable routers: ok (<6), warning (6-11), high (12-23), critical (24+) events
  • Area score: 100 - (flaps*5 + events), capped at 0
