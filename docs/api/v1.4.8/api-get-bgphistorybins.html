BGP history bins

GET /bgp/history/bins

Event-density buckets over a window for the scrubber strip — the AS-wide overview you scan to pick a prefix. Bucket width adapts to the window (buckets≈200 by default). Announce/change counts exclude seed-origin opens; withdrawals count terminal closes.

Auth: all authenticated roles

Query params: as_id (required), from/to (required, RFC 3339); optional prefix + match, routing_domain_id, device_id, and buckets (default 200, max 1000).

Response: 200 OK

{
  "bucket_seconds": 60,
  "from": "2026-07-01T10:00:00Z",
  "to": "2026-07-01T11:00:00Z",
  "bins": [ { "t": "2026-07-01T10:05:00Z", "announces": 3, "changes": 12, "withdrawals": 1, "peer_changes": 0 } ]
}

bins is sparse — only non-empty buckets are returned; t is the bucket start. bucket_seconds = ceil((to−from)/buckets).

Errors: 400 if as_id or the window is missing/invalid.
