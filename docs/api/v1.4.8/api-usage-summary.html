Usage Summary

GET /api/v1/usage-summary

Returns deployment-wide aggregate counts for the in-app startup usage ping: total devices, total links, and the set of protocols configured anywhere in the installation. Authenticated (any role); license state never gates reads.

Response: 200 OK

{
  "devices": 64,
  "links": 244,
  "protocols": ["ospfv2", "ospfv3"]
}

protocols is the DISTINCT set of protocol_instance.protocol values (ospfv2, ospfv3, isis, eigrp, bgp), alphabetically ordered, or [] when none are configured. The frontend (useUsageSummary) encodes these into the anonymous UTM usage payload, so the signal reflects the whole installation rather than whichever topology view is open.
