Device Management (Admin)

Delete Device

DELETE /api/v1/devices/{deviceID}

Permanently removes a device and all associated data (interfaces, interface_stats_latest, snmp_target, device_area_membership) via FK CASCADE. Engineer or admin.

In the same transaction the device's addresses (its current polling target, its router-id and every recorded management address) are removed from the seed list of every EIGRP recorder declared in that device's own network, and those recorders' config_version is bumped so the collector-manager re-reads the shortened list. Without that prune a delete would not stick: seed lists are operator config no cascade touches, and the manager re-creates an SNMP target for every declared seed each time it registers a recorder — a service restart is enough. Pruning never disables a recorder (recording matches on network membership, so an emptied seed list still records the whole network), and a router that is still live and still speaks EIGRP returns through ordinary LLDP/CDP discovery on its own evidence rather than on a stale config line. The network scope matters: the same management address legitimately exists in several networks, so recorders in other networks are never touched. A device with no resolvable network leaves every seed list alone and logs a warning.

Response: 204 No Content

Error responses:

  • 401 Unauthorized -- Missing or invalid access token
  • 403 Forbidden -- Non-admin user
  • 404 Not Found -- Device does not exist
