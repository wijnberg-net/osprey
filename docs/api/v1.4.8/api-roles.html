Roles

  • admin — Full access to all endpoints, including user management, system settings, audit log, API keys, backup/restore, and active sessions.
  • engineer — Infrastructure management: hierarchy CRUD, collector CRUD, SNMP targets/profiles, alert rules/channels, notification channels, maintenance windows, icon packs, device/link deletion, DNS refresh, and SSH session history. No access to user management, system settings, audit log, or backup/restore.
  • operator — Reads topology data, manages permitted layouts and personal settings, and can acknowledge, resolve and permanently ignore alerts. Can read own SSH session history, but cannot open an SSH/Telnet terminal. This role is not a read-only security boundary.
