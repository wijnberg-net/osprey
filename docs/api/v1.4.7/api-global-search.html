Global Search

Search Devices and Interfaces

GET /api/v1/search

Global search across devices and interfaces.

Query Parameters:

  • q (required) — Search query string (max 200 chars)
  • limit (optional) — Max results per category (default 10, max 50)

Response: 200 OK

Searches device fields (hostname, dns_name, router_id, vendor, model, platform, software_version) and interface fields (if_alias, if_name, if_descr, ip_address). If query is a valid IP or CIDR, also performs subnet containment search. Results prioritize prefix matches. Available to all authenticated users.
