List Sign-In Providers

GET /api/v1/auth/providers

Rate limit: 30 requests per minute per IP (burst 10, shared with the SSO flow endpoints).

Returns the enabled identity providers for the login page plus the local-login policy — one round-trip for everything the page needs. Nothing beyond id/name/type is exposed.

Response: 200 OK

{
  "providers": [ { "id": "uuid", "name": "Corporate SSO", "type": "oidc" } ],
  "local_login": "enabled"
}

local_login is enabled, admins_only or disabled (see Login notes).
