GET /bgp/rib-paths

List all received BGP paths for a specific prefix. Returns per-peer path detail from bgp_rib_entry with joined peer metadata (peer IP, peer AS, peer router ID). Enables "show ip bgp <prefix>" style analysis.

Auth: all authenticated roles

Query params:

Param Type Required Description
prefix CIDR Yes Exact prefix to look up (e.g. 203.0.113.0/24)
device_id UUID Yes Selecting device (BMP target perspective)
as_id UUID Yes Autonomous system
at RFC 3339 No Time-travel timestamp. See the historical-mode note below.

The three ID/prefix parameters are required; the endpoint returns 400 if any is missing.

Historical mode (at): per-peer received-path history exists where full-RIB recording (history_mode: "full") covered the AS at at. The endpoint gates on that capability: with coverage it serves the recorded per-peer paths from bgp_rib_entry_history (the requesting device's own rows only); without it — or when the covered prefix simply had no recorded paths at at — it returns an empty paths array, path_count: 0, and a notice explaining why, rather than returning misleading live data.

Response: 200 OK

Errors: 400 if any of prefix, device_id, or as_id is missing.
