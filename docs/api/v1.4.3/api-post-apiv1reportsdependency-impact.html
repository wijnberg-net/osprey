POST /api/v1/reports/dependency-impact

POST /api/v1/reports/dependency-impact

Computes detailed impact for a specific failure scenario (drill-down from overview).

Auth: Any authenticated user.

Request body:

{
  "scenario_type": "peer_as",
  "scenario_id": "64512",
  "pi_id": "uuid",
  "as_id": "uuid"
}
  • scenario_type -- One of: peer_as, srlg, device, critical_pair
  • scenario_id -- Entity identifier (peer AS number, SRLG UUID, device UUID, or comma-separated link UUIDs)
  • pi_id (optional) -- Protocol Instance for topology scope
  • as_id (optional) -- Autonomous System for BGP scope

Response: 200 OK
