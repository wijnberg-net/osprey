BMP Targets & BGP

BMP target management and BGP data read endpoints. The BMP server populates bgp_peer and bgp_rib_entry/bgp_best_path tables; these endpoints expose the data to the frontend and external clients.

BMP target writes (create/update/toggle/delete) live under the engineer-or-admin route group (requires admin or engineer role). BMP target reads and the BGP read endpoints (peers, routes, summary) are accessible to all authenticated roles in every license state — consistent with collector status reads, so the sidebar can show BMP connection state to viewers.
