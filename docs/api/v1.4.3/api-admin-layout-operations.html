Admin Layout Operations

Set Default Layout

PUT /api/v1/layouts/{layoutID}/set-default
PUT /api/v1/areas/{areaID}/layouts/{layoutID}/set-default

Clears any existing default layout for the scope and sets the specified layout as the new default for all users who have not explicitly activated a different layout.

Response: 200 OK

{"message": "default layout set"}

Error: 404 Not Found — Layout does not exist
