Create BGP-LS peer

POST /bgpls/peers

Create a lane B peer. Required: name, as_id, routing_domain_id (must exist and belong to as_id), peer_address, remote_as and local_as. Optional: description, peer_port (179), source_address, hold_time (0 or 3–65535; absent 90), max_bgpls_nlri (default 100000), and bgpls_strict_eor (default false). New peers are enabled. Osprey dials out; nothing listens on Osprey's side.

Auth: admin, engineer. Response: 201 Created.
