Error Codes

Code HTTP Status Description
BAD_REQUEST 400 Malformed JSON, invalid data
VALIDATION_ERROR 400 Field value fails validation (e.g., exceeds max length, invalid format)
VALIDATION_REQUIRED 400 Required field is missing or empty
AUTH_REQUIRED 401 No token, invalid token, expired token, or wrong credentials
AUTH_FORBIDDEN 403 Insufficient role or access denied to resource
NOT_FOUND 404 Resource or endpoint does not exist
METHOD_NOT_ALLOWED 405 Endpoint does not accept this method; Allow lists supported methods
CONFLICT_DUPLICATE 409 Duplicate key or constraint violation (e.g., duplicate name)
RATE_LIMITED 429 Too many requests (includes Retry-After: 60 header)
INTERNAL_ERROR 500 Unexpected database or server error
