SNMP Target Summary (Non-Admin)

Get SNMP Target Summary

GET /api/v1/snmp-targets/summary

Returns aggregate counts of SNMP targets. Available to all authenticated users (not admin-only). Used by HealthPopover to show SNMP poller status without fetching the full target list.

Response: 200 OK

{
  "total": 12,
  "active": 10,
  "stale": 2
}

Notes:

  • total is the count of all SNMP targets.
  • active is the count of targets that have been polled recently (within 2x their poll interval).
  • stale is the count of targets that have not been polled within the expected window.

Error responses:

  • 401 Unauthorized -- Missing or invalid access token
