BGP-LS

BGP-LS (AFI 16388 / SAFI 71, RFC 9552) arrives over two lanes: lane A rides a BMP target and lane B is a receive-only peering Osprey dials. Both stage link-state objects and project them into the canonical topology under a managed bgpls:<source-uuid> collector. Areas already fed by a non-BGP-LS recorder are suppressed. A source refuses only when objects were lost (budget, full ingest lane, failed publish, unparsable BMP message, or malformed NLRI skipped under RFC 9552 §8.2.2). While a dump is active, the prior projection stands. Observed EoR opens the next epoch and permits the cutoff sweep. Quiet inference opens the epoch by default without sweeping and leaves durable conformance provenance on the source; per-source strict EoR instead records the inference while continuing to hold the prior epoch.
