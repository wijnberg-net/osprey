DNS Tools (Admin)

Refresh Reverse DNS

POST /api/v1/dns/refresh

Triggers a full re-resolution of all reverse DNS (PTR) records for device router IDs and interface IPs across the entire system. The engine clears its DNS caches and re-resolves all IPs in the background. Use this endpoint after network renumbering events, device replacements, or DNS zone updates to force a refresh of all cached DNS lookups. Admin-only.

Request body: None (empty POST)

Response: 200 OK

{
  "status": "refresh requested"
}

Notes:

  • The refresh happens asynchronously. DNS caches on the engine are cleared immediately; re-resolution of all IPs begins after the request completes.
  • Device display names across the topology, incidents, diagnostics, and reports (when display.device_name_mode is set to dns) will reflect the refreshed DNS results.
  • Audit log entry is created with action "refresh" and entity_type "dns".

Error responses:

  • 401 Unauthorized -- Missing or invalid access token
  • 403 Forbidden -- Non-admin user
  • 500 Internal Server Error -- NATS publication failure or database error
