Update, toggle or delete a BGP-LS peer

PUT /bgpls/peers/{id} / POST /bgpls/peers/{id}/toggle / DELETE /bgpls/peers/{id}

Merge-update (enabled is toggle-only; explicit empty source_address clears it; routing_domain_id re-homes with belongs-to-AS validation; bgpls_strict_eor uses boolean presence semantics so omission preserves it and explicit false clears it), toggle, and delete. Config changes restart the peer session within the dialer's 30 s reconcile.

Auth: admin, engineer.
