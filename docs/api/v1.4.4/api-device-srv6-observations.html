Device SRv6 observations

GET /api/v1/devices/{deviceID}/srv6 (authenticated application endpoint, UUID guard) returns { "live_only": true, "observations": [...] }. Each observation has area_id, device_id, observed_at and data containing locators, capabilities, adjacencies and invalid_advertisements. Empty observations means no decoded source data; an observation with an empty locator list means no locator was advertised. at requests return 400; database errors return 500. This endpoint is not yet part of the published OpenAPI or restricted-key allowlist.

EVPN members expose optional srv6_services[]: SID/base SID, behavior code, raw label evidence and complete/unresolved status. The EVPN detail endpoint also resolves owners within the EVI observation ASes and reports unique, ambiguous or unknown ownership. SRv6 service state is live-only.
