List BGP-LS peers

GET /bgpls/peers

List lane B BGP-LS peers, optionally ?as_id=<uuid>. Each row carries config and dialer state, the object-loss refusal set, bgpls_dump_session, and the 000190 completion fields bgpls_strict_eor, bgpls_completion_inferred, bgpls_completion_af, optional bgpls_completion_at, and bgpls_completion_session. bgpls_completion_af is currently link-state after completion (AFI 16388 / SAFI 71; explicit for future-family separation). Joined: as_name, routing_domain_name.

Auth: all authenticated roles. GET /bgpls/peers/{id} returns one.
