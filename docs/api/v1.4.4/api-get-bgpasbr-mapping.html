BGP ASBR mapping

GET /bgp/asbr-mapping

Returns distinct (next_hop, device_id) pairs from the BGP best-path table. Used by the frontend to map BGP next-hop IPs to topology devices for route table display.

Auth: all authenticated roles

Query params: None.

Response: 200 OK

[
  {
    "next_hop": "198.51.100.2",
    "device_id": "uuid"
  }
]

Returns an empty array if no BGP best paths have resolved device mappings.
