BGP-LS SR-policy observations (2026-09-09)

GET /api/v1/bgpls/objects?type=policy uses the existing authenticated paginated reader, with as_id, protocol_id=9, target_id, peer_id, include_stale, limit and offset filters. Each row is an exporter/peer-view/Add-Path observation, never a best-policy selection. Rows include path_id, reporter.policy_source, reporter.policy_peer and policy. The latter has wire_format, optional headend_ipv4/headend_ipv6, origin, endpoint, color, originator_asn, originator_address, discriminator, optional names and state:{priority,flags,preference}, and segment_lists in wire order. Each list carries flags, mt_id, algorithm, weight and segments; segments carry type, flags, encoded_sid or label when decoded, sid_present and base64 raw. Base64 attributes_raw, unconsumed_tlvs and notes preserve diagnostic scope. withheld/attrs_discarded/stale retain their existing meanings; absent state is not inactive. No new route registration or read-only-key permission. The measured junos-legacy-v6 layout is explicitly labeled; raw flags do not prove forwarding installation. Other extension attributes remain unconsumed.
