# Contributing

Thank you for your interest in Osprey. A note up front, so nobody wastes their
time: **Osprey is commercial, closed-source software.** This repository
distributes compiled releases and documentation — it does not contain the
source code.

## What genuinely helps

- **Bug reports.** Use the
  [bug report template](https://github.com/wijnberg-net/osprey/issues/new/choose).
  The most valuable reports name the Osprey version, the OS, the affected
  service, and include the relevant `journalctl` output — with credentials,
  SNMP communities, and internal addressing redacted.
- **Feature requests.** Tell us the operational problem first, your proposed
  solution second. Requests grounded in a real workflow ("during maintenance
  windows we need…") carry far more weight than abstract wishes.
- **Documentation feedback.** If the [user guide](https://github.com/wijnberg-net/osprey/wiki)
  is wrong, unclear, or missing something, open an issue and name the page.

## What we cannot accept

- **Code pull requests.** There is no public source to change. Pull requests
  against this repository are limited to corrections in the files actually
  hosted here (README, documentation) and may be accepted at our discretion.
- **Feature bounties or paid prioritisation via issues.** For commercial
  arrangements, contact sales@wijnberg.net.

## Security issues

Never in a public issue — see [SECURITY.md](SECURITY.md) for the private
reporting channel and what to expect from us.

## Conduct

All interactions in this repository fall under the
